# Swaad Vadodara — Food Delivery

Vercel-ready Next.js food delivery experience focused on Vadodara.

## Functional features
- Search dishes and restaurants
- Filter by cuisine/category
- Local Vadodara favourites
- Add/remove cart items
- Automatic order total
- Checkout/order confirmation simulation
- Responsive mobile and desktop UI
- No API keys required

## Run
`npm install && npm run dev`

## Vercel
Import this repository into Vercel and deploy with the detected Next.js settings. No environment variables are required.

For real payments, restaurant inventory, authentication, live delivery tracking and persistent orders, connect a backend/database/payment provider to the existing UI.
